# YottaFlex AI Employee Onboarding & Offboarding Workflow Automation

An enterprise workflow automation system governing personnel pre-boarding, onboarding, access provisioning, equipment custody tracking, offboarding, and compliance audit history.

Built using **Python 3.10+**, **SQLite 3**, and **Streamlit**.
